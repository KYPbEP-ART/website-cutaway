 KYPbEP.ART — портфолио-платформа с авторизацией и монетизацией

## 🎯 Что это

Личный сайт-портфолио с полноценным бэкендом: регистрация/вход, JWT-авторизация, 
защита от брутфорса. Служит витриной проектов и новостей, а в планах — платформа 
для продажи копий проектов (СБП) и обсуждения их в комментариях.

**Зачем не просто «страница на GitHub Pages»:** визитка — это скучно и не показывает 
инженерных навыков. Здесь есть реальный backend, безопасность и продуктовая 
логика (монетизация, сообщество).

## ⚙️ Что уже работает

### Frontend
- **Терминально-ретро эстетика**: monospace, скан-линии на изображениях, 
  CRT-эффект, акценты зелёный/оранжевый/голубой.
- **Динамический контент**: проекты и новости подгружаются из JSON, 
  сортируются по дате, отображаются карточками со статусами 
  (`в разработке` / `завершён` / `заморожен`).
- **Профиль пользователя**: страница «обо мне» с сайдбаром (друзья, уровни 
  знаний, контакты), сеткой стека и лентой личных новостей.
- **Модальное окно авторизации**: вход/регистрация, переключение вкладок, 
  сообщения об ошибках.
- **Состояние авторизации** в `localStorage`, кнопка выхода, отображение профиля 
  в шапке.

### Backend (Rust + Axum)
- **Регистрация/вход** с валидацией (длина логина, формат email, длина пароля).
- **Хеширование паролей** через **Argon2** (memory-hard, устойчив к GPU-атакам).
- **JWT-токены** с expiration, защищённый эндпоинт `/api/me`.
- **Rate limiting** по IP: 5 попыток за 5 минут → блокировка на 5 минут 
  (защита от брутфорса).
- **SQLite + пул соединений** (r2d2), миграции через `init_db`.
- **CORS, tracing**, структура `routes/models/db`.

## 🛠️ Стек

- **Frontend:** TypeScript, Vite, нативный DOM (без фреймворков), CSS 
  с переменными и модулями.
- **Backend:** Rust, Axum, Tokio, rusqlite + r2d2, argon2, jsonwebtoken, 
  tower-http.
- **Инфраструктура:** NixOS (декларативное окружение), GitHub.

## 🧩 Архитектура

- `src/ts/main.ts` — точка входа, авторизация, динамическая загрузка контента.
- `src/style/` — `variables.css` (тема), `main.css` (база), 
  `widgets.css` (карточки, статусы), `profile.css` (страница «обо мне»).
- `src/data/` — `projects.json`, `news.json`, `personal-news.json`.
- `backend/src/` — `routes/` (auth, users), `models/` (user), 
  `db/` (sqlite), `rate_limiter.rs`.

## 🚧 В планах

- **СБП-оплата** за копии проектов (монетизация).
- **Комментарии** к проектам и новостям (с привязкой к пользователю, 
  защита от XSS).
- **Профиль пользователя** как отдельная страница с редактированием.
- **Демо-режим** для показа без бэкенда (чтобы работодатель мог открыть 
  по ссылке).
- **Унификация навигации**: убрать дублирование между `index.html` 
  и `about.html`.

## 📦 Запуск

```bash
# Backend
cd backend
export JWT_SECRET=$(openssl rand -base64 32)
cargo run

# Frontend
npm install
npm run dev
```

📌 Статус

Backend с auth и безопасностью — работает. Frontend-витрина — работает.
Монетизация и комментарии — в планах.
